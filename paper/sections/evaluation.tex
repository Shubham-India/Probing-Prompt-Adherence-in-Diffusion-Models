\section{Evaluation and judge validation}\label{sec:evaluation}
The first-pass judge (J1) combines open-vocabulary detection with CLIP colour classification. It counts a missing object as a failure for binding, count and spatial constraints, so conditional fields are stored additively beside the legacy fields. Its pilot check on 40 images (Table~\ref{tab:pilot-validation}) used labels that began as an AI draft and were edited by the project owner; it is not independent.

\paragraph{DEV audit protocol (pre-declared).} A blinded, seeded, stratified sample of $540$ (image, constraint) items from the R2a DEV core ($20$ practice items discarded; $100$ items double-annotated) is labelled by humans who see only an opaque image and a neutral question (a colour, a count, a presence answer, or which object is further left) with ``not visible'' and ``ambiguous'' answers. Accuracy is population-weighted with a stratified bootstrap; a constraint type is eligible for confirmatory use only if its weighted accuracy is at least $0.85$. No other criterion is added after the data are seen. A synthetic probe with exact truth is specified as a code-path ceiling check and is not a validation on natural images.
