\section{Reproducibility and provenance}
Code is versioned in Git; each run records a run identifier, the commit, the pinned model revision, the resolved configuration, the library and GPU environment, and checksums of every output. Integrity is verified by independent scripts before any analysis, and every number in this draft is loaded from \texttt{outputs/results\_draft/results.json} through generated tables and macros (\texttt{python src/build\_draft.py}); the provenance of each result is listed in \texttt{docs/RESULTS\_PROVENANCE.md}.
