\section{Reproducibility and provenance}\label{sec:repro}
Code is versioned in Git. Every run records its identifier, source commit, pinned model and judge revisions, resolved configuration, software and GPU environment, and SHA-256 checksums of every output; archives are verified file by file before any analysis. The protocol file binds the hashes of \frozenFiles{} code, configuration, benchmark and documentation files, the judge definition, the development-set constants and the three test-stage manifests; test workers and the confirmatory analysis refuse to run unless it verifies. Development constants, audit verdicts and the quality-guard result are stored under \texttt{docs/evidence/}; every number in Sections~\ref{sec:evaluation}--\ref{sec:resDEV} is generated from those files by \texttt{paper/make\_paper\_assets.py} and \texttt{scripts/paper\_dev\_tables.py}. Test-split tables and figures are generated by \texttt{partial/partial\_report.py} (partial) or \texttt{scripts/final\_report.py} (complete), and the exploratory analyses of Section~\ref{sec:resROBUST} by \texttt{partial/robustness.py}, which reuses the frozen estimator functions on the saved judged rows. The partial-test numbers come from archive \texttt{r3-test-partial-20261020T134300Z-40ade4d} (source commit \texttt{40ade4d}, protocol verified); an independent re-judging of the same images on different hardware reproduced every judged outcome. Each partial-test number in the text is a generated macro (\texttt{tables/partial\_robust\_numbers.tex}) traceable to \texttt{reports/partial/robustness.json} or \texttt{partial\_results.json}. Decisions and deviations are logged with dates in \texttt{docs/R3\_DECISION\_LOG.md}. Images, latents and human labels are not distributed.
