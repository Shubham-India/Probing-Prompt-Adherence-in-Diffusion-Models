\paragraph{Limitations of this analysis.}
\begin{itemize}
\item Missing TEST shards (not imputed): TEST\_CORE shard 2; TEST\_COMMIT shard 2; TEST\_CAG\_SIZE shard 0; estimates cover only the scene groups of the present shards.
\item This is not the registered confirmatory analysis, which requires all nine shards; Holm-adjusted p-values are shown for completeness only.
\item HA is exploratory by its failed DEV precision gate; the full-resample control failed on DEV.
\item Only the presence judge met the audit criterion (single annotator, no valid double annotation); count, binding, spatial and size outcomes are exploratory.
\item HE contrasts with constant guidance use only the 67 scenes with both A1 and CAG images (one CAG shard); the comparison with the reversed schedule uses all scenes with CAG arms.
\end{itemize}
