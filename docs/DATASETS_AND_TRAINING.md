## 2. What is actually trained
1. **Nothing in the diffusion model.** Stable Diffusion 1.5 is used with fixed weights; the intervention operates on attention logits at inference time.
2. **Auxiliary predictors for HB only** (and only by the plan): L2 logistic regressions in `src/predict_failure.py` (`StandardScaler` + `LogisticRegression(C=0.3)`) that predict a constraint outcome from (a) prompt-structure/design features, (b) initial-noise features reproducible from the seed (`features.py`), and (c) attention-conflict features. Labels are the judged outcomes of the same images; training and tuning use **DEV only** with `GroupKFold` grouped by scene (the pilot analysis groups by prompt); the frozen model is applied once to TEST. No pixels are used. Hyper-parameters (`C`, windows, feature sets) are chosen on DEV and frozen in Addendum B.
3. **Nothing else.** J1 uses pretrained OWL-ViT and CLIP unchanged; a second judge (J2) does not exist and no VLM has been chosen. No classifier is trained on human labels; the labels only estimate J1's error rates and select which constraint types are confirmatory.

## 3. Where each thing comes from and how to prepare it
| Need | Command | Notes |
|---|---|---|
| All models (local) | first call of `generate.load_pipeline` / `evaluate.load_models` downloads into `models/` | large (about 3.7 GB locally); deliberate action: do it once, never inside a run that does not need it |
| Benchmark V2 files | `python src/benchmark_v2.py --validate` (and the build command in `data/benchmark_v2/DATASHEET.md`) | deterministic; hashes in `hashes.json` |
| Code bundle for Kaggle | `python kaggle/make_bundle.py --commit <SHA> --out kaggle_bundle` | excludes weights, outputs, pilot validation images |
| Core dataset for Kaggle | `python kaggle/make_core_dataset.py ...` | from the audited R2a folder |
| Audit packages | `python src/audit_dev.py sample ...` / `pilot ...` | seeded; keys stay in `key/` |
